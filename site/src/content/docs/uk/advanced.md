## Встановлення агента без інсталятора

Зберіть автономну копію агента з [вихідного коду](https://github.com/andriykohut/promin). Тоді на тому ПК не потрібен встановлений .NET:

```
dotnet publish src/Promin.Agent -c Release -r win-x64 --self-contained true -o src/Promin.Agent/bin/publish/win-x64
```

Скопіюйте папку на ПК і задайте код кімнати (`| Out-Host` потрібен, щоб побачити рядок відповіді):

```
.\Promin.Agent.exe --set-room-code 482913 | Out-Host
```

Потім виконайте `.\Promin.Agent.exe --install` у терміналі **від імені адміністратора** й додайте ПК на консолі, як зазвичай.

## Команди агента

Запустіть `Promin.Agent.exe` у його папці з одним із цих параметрів:

| Параметр | Що робить |
|---|---|
| `--install` | Реєструє агент як службу, що запускається разом із Windows, додає правило брандмауера й закриває доступ до папки з даними (термінал від імені адміністратора) |
| `--uninstall` | Видаляє службу та її правило брандмауера, залишаючи файли з даними про консоль, ідентифікацією та блокуванням |
| `--windowed` | Показує трансляцію у звичайному вікні, а не на весь дисплей |
| `--reset-pairing` | Забуває консоль, до якої додано ПК, і знімає блокування, щоб ПК можна було додати знову. Запущений агент пам’ятає їх до перезапуску, тож після цього перезавантажте ПК (термінал від імені адміністратора) |

## Мережеві порти

Обидва порти UDP.

| Порт | Для чого |
|---|---|
| 17843 | Агент приймає з’єднання від консолі |
| 17844 | Агенти повідомляють про себе, а консоль їх слухає |

## Де що зберігається

| Що | Де |
|---|---|
| Дані й журнал консолі | `%LocalAppData%\Promin` |
| Налаштування консолі, зокрема де востаннє було вікно керування | `%LocalAppData%\Promin\settings.json` |
| Дані й журнал агента | `%ProgramData%\Promin\Agent` |
| Блокування на ПК з агентом | `%ProgramData%\Promin\Agent\lock.json` |
| Код кімнати на ПК з агентом | `%ProgramData%\Promin\agent.json` |
| Файли, надіслані на ПК з агентом | `Promin` на робочому столі того, хто там увійшов у систему |
