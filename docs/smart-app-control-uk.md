# Як вимкнути інтелектуальне керування програмами для Promin

[English](smart-app-control-en.md)

Програми Promin поки не мають цифрового підпису ([#49](https://github.com/andriykohut/promin/issues/49)). У Windows 11 є захист **«Інтелектуальне керування програмами»** (Smart App Control), який блокує програми без підпису, і дозволити якусь одну програму в ньому не можна. На кожному ПК, де працює Promin, цей захист має бути **вимкнуто** — і залишатися вимкненим.

- **Увімкнуто**: Windows блокує Promin.
- **Оцінювання**: поки нічого не блокується, але згодом Windows може сама його ввімкнути, і тоді Promin перестане запускатися.
- **Вимкнуто**: Promin працює.

Без інтелектуального керування програмами ПК гірше захищений від невідомих програм. Якщо цим ПК керує хтось інший, спершу отримайте дозвіл.

## Як зрозуміти, що його ввімкнуто

- Встановлення Promin відкривається сторінкою із заголовком **ВАЖЛИВО: Windows заблокує Promin на цьому ПК**.
- Windows показує повідомлення «Part of this app has been blocked … Promin.Agent.exe» (воно може бути англійською).
- Встановлення агента завершується повідомленням «не вдалося налаштувати його як службу (код виходу 4551)».

## Як вимкнути

1. Відкрийте **«Пуск»**, введіть **«Безпека у Windows»** і відкрийте цю програму.
2. Виберіть **«Керування програмами та браузером»**.
3. У розділі **«Інтелектуальне керування програмами»** виберіть **«Параметри інтелектуального керування програмами»**.
4. Виберіть **«Вимкнуто»**. Якщо Windows попросить дозволу, натисніть **«Так»**.
5. Поверніться до встановлення Promin і натисніть **«Перевірити ще раз»**, потім **«Далі»** і **«Встановити»**.

Якщо встановлення вже завершилося з кодом виходу 4551, вимкніть інтелектуальне керування програмами, як описано вище, і запустіть встановлення ще раз.

## Якщо перемикач неактивний

Цим ПК керує організація, і змінити цей параметр можна лише через неї. Попросіть вимкнути інтелектуальне керування програмами або дозволити Promin.

## Чи можна ввімкнути його знову

У Windows 11 з оновленнями від квітня 2026 року чи новішими інтелектуальне керування програмами можна знову ввімкнути там само. У старіших версіях вимкнення остаточне, доки Windows не перевстановлять. Але поки Promin встановлено, тримайте його вимкненим: коли воно ввімкнуте, Windows блокує Promin щоразу під час запуску.
